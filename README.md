# Недостижимый реализм

Реалистичная и простая сборка Minecraft 1.20.1, целью которой является воссоздать человеческую историю начиная с каменного века, и заканчивая нашим временем. Финал - полёт в космос, такой пустой и безлюдный... Ванильные механики переделаны, чтобы соответствовать реализму. Например, светокаменная пыль - это люминисцентный материал, а редстоуновая пыль представляет из себя компонент для травления плат и создания "супернизкого" напряжения для логических схем через пьезоэлектрику с кварцевыми лампами. Промышленность, металлургия и космос реализованный через TerraFirmaCraft, Create с его аддонами - Creating space, Big Cannons, New Age, Clockwork и Immersive Engineering для электрификации механизмов. Сборка пытается быть близка к идеям "того самого" майнкрафта - сборка преследует минималистичный подход, что должно хорошо сказываться на оптимизации и ощущении ретро-инди игры. 

> Не будем отменять так же тот факт, что всё таки майнкрафт не может быть полностью реалистичным, поэтому эта сборка лишь пытается быть похожей на реальную жизнь, и не может олицетворять реализм в полной мере!

## Важно перед запуском

### Разблокировка рецептов ракетных двигателей

В сборке присутствует мод **Creating Space**, содержащий десятки чертежей ракетных двигателей. Чтобы **сразу открыть все доступные дизайны**, используйте команду:
/creatingspace addAllDesigns

### Режим читов обязателен

> [!WARNING]
> **В одиночной игре мир должен быть открыт с включёнными читами!**
> 
> Команда `/creatingspace addAllDesigns` требует уровень прав оператора (OP) и **не работает без читов**.
